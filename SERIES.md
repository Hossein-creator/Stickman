# "serie": numbered series job

User, 2026-11-09: "wenn ich generate schreibe machst du wie immer aber wenn ich serie schreibe baust du eine serie".
- "generiere" / "generate" → `GENERATE.md` as always (4 single reels, winner format).
- "serie" → this job.

## Why
"in letzter Zeit bekommen meine Social-Media-Accounts keine Follower und keine Aufrufe mehr ... längere Videos generieren und nummerieren wie eine Serie, damit Leute mir folgen" + "es soll eine spannende Geschichte sein, damit Leute es bis zum Ende schauen".

## Rules
- One run = **one series** about the same stickman couple (same look, same names/colours in every part), **4 parts** ("PART 1/4" ... "PART 4/4" always on top).
- Each part **30-60 s** (not longer: watch time to the end matters more than length).
- The story idea comes from a relationship video with **≥ 1M views** (rule above), stretched into a gripping arc: Part 1 hook + conflict, Parts 2-3 escalation and a twist, Part 4 payoff/emotional ending.
- **Hook in the first 2 s** of every part (action, not a slow intro). Something new happens every 3-5 s.
- Every part except the last **ends on a cliffhanger**, then an end card "PART 2 → FOLLOW" (no fade-out before the open question).
- Parts 2-4 start with a **2-3 s recap** ("PREVIOUSLY ...") so new viewers get it.
- Caption: "Part N/4", the cliffhanger question, "Follow for Part N+1"; parts post in consecutive slots in order.
- Only relationship. Source rules and the virality check (≥ 1M views) as in `GENERATE.md` step 2.
- Code only, same look and rig as all reels. 1080×1920.

## Steps
1. Find ≥ 1M-view relationship videos (`GENERATE.md` step 1-2), pick the one with the most gripping story.
2. Write the arc (4 parts, beat list per part, cliffhangers) to `viral/YYYY-MM-DD-series.md`; commit.
3. Build each part (`videos/NN-slug-part-N`), snap-check, render in the foreground, commit right after each part.
4. Caption per part: "Part N/4", the cliffhanger question, "Follow for Part N+1", 6-8 hashtags (+ #series #part1 ...).
5. Send each part to Telegram in order, consecutive slots (`DAILY-JOB.md`); in chat only "Das Video wurde erstellt."
6. Log in `DAILY-JOB.md` and `REFERENCE-ANALYSIS.md`, commit and push.
