# Silent Stickman

Stille Stickman-Kurzvideos für TikTok, Instagram Reels und YouTube Shorts. Alles ist aus Code gemacht (HyperFrames + Canvas), ohne KI-Bilder.

- `NICHE.md` – Nische, Themen, Zielgruppe
- `STYLE.md` – Stil-Regeln und Ablauf
- `shared/` – Engine (Rig, Effekte, Text) und Schriften
- `tools/` – Sound-Synth und Sync-Skript
- `videos/<nr-name>/` – ein Projekt pro Video (`scene.js` = Bild, `sound.mjs` = Ton)
- `ready/` – fertige MP4s und Captions
